Task 01 — 
Text and Number Tools
A beginner-friendly Python project that analyzes a sentence and checks whether an integer is prime.

Features:-
Counts the words in a sentence.
Finds the longest word.
Reverses a sentence character by character.
Checks whether a number is prime.
Handles invalid integer input.
Requirements
Python 3.8 or newer
No external libraries required
How to Run
Download or clone this repository.
Open a terminal in the project folder.
Run the following command:

python main.py
If your system uses python3, run:


python3 main.py
Follow the prompts to enter a sentence and an integer.

Functions
count_words() — Counts words in a sentence.
find_longest_word() — Finds the longest word.
reverse_sentence() — Reverses the sentence.
is_prime() — Checks whether an integer is prime.
main() — Runs the program and displays the results.
Notes:-
The longest word is selected based on character length. If multiple words share the maximum length, the first one is returned. Sentence reversal reverses every character, including spaces and punctuation.
